# Lab 7: Practice Problems

These problems reinforce everything covered in Lab 7 and Lab 8: binary search tree (insertion, searching, deletion, inorder/preorder/postorder traversal, minimum, maximum, height) and heap (max-heap and min-heap, heapify up and down, heap sort, and the STL `priority_queue`). Work through them in order: **Easy** first, then **Medium**, then **Hard**, and try to solve each one without looking at editorials first. Solving these on the actual judge (not just reading them) is what builds real fluency.

The Easy and Medium problems only need what you learned in this lab: walk a BST using its left/right rule, and use a heap whenever you need the largest or smallest element quickly. On LeetCode the tree is already built for you as a `TreeNode` with `left` and `right` pointers, exactly like the `Node` in the lab. The Hard problems combine a heap or an ordered set with a bit more thinking, so it is fine to come back to them later. Each problem links directly to its statement on the judge. Create an account on each site if you do not already have one: most of them (Codeforces, CSES, HackerRank, LeetCode) are free. The UVA problem is included via VJudge, which mirrors the UVA archive and lets you register and submit with a single account.
