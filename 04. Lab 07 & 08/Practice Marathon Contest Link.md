# Data Structure Lab: Practice Marathon Contest 04

This practice marathon is designed to reinforce the concepts covered in Labs 7, 8, and 9 through practical problem solving.

The problem set focuses on Binary Search Trees (BST), tree traversal, recursion, heap operations, priority queues, graph representation, adjacency lists, vertex degrees, and related applications discussed in class. The problems are arranged from easier to moderately challenging to help you build confidence gradually.

Please prioritize **C++** when solving and submitting the problems. Use your own registered VJudge account and focus on understanding the underlying concepts and problem-solving techniques rather than simply getting accepted submissions.
