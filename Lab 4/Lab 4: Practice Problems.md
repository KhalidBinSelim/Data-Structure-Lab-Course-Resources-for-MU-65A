# Lab 4: Practice Problems

These problems reinforce everything covered in Lab 4: singly linked lists (traversing, searching, insertion, deletion), doubly linked lists (prev/next pointers, forward and backward traversal), and circular linked lists (tail pointer, wrap-around, round-robin and Josephus-style problems). Work through them in order: **Easy** first, then **Medium**, then **Hard**, and try to solve each one without looking at editorials first. Solving these on the actual judge (not just reading them) is what builds real fluency.

Each problem links directly to its statement on the judge. Create an account on each site if you do not already have one: all of them (HackerRank, LeetCode, CSES) are free. Most of these problems give you a ready-made `ListNode` or `Node` structure, so read the provided code carefully before writing your own functions.
