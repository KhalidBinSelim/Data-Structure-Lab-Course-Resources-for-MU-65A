This folder contains the necessary code files and implementations for the Data Structure Lab course. The purpose of these files is to help students understand the practical implementation of fundamental data structures and related algorithms discussed in the lab classes. Students are encouraged to study the code carefully, understand the logic behind each implementation, and practice writing and modifying the programs on their own. Some of the code files in this folder were adapted from materials provided by my Data Structure course instructor at SUST, Enamul Hassan, Assistant Professor (Study Leave), Department of CSE, SUST. Sir is currently pursuing his PhD at The University of Texas at Dallas. 

_**Important Note:**_

These materials are provided for educational and course-related purposes. Students are expected to use the code as a reference for learning and practice rather than simply copying the implementations without understanding them.
